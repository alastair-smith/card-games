# Play Cards Storybook

The components of Play Cards, the app for playing multiplayer card games online with friends, each shown on its own in the states it can be in, from a button to a full game of Yaniv.

## What it's for

- **Building and reviewing UI:** each story renders a component with fixed props, so a state that's hard to reach in a real game, such as a Yaniv call or the end of a game, is one click away
- **Checking both screen sizes:** each component's Docs page shows every story at a smaller and a larger screen size side by side, and the viewport toolbar sets the size of a single story
- **Testing:** in CI, each story runs as a test in a real browser. A story's `play` function clicks or types through it and checks the result, and the accessibility addon warns about problems it finds
- **Previewing pull requests:** each pull request that changes the app gets its own copy of this Storybook

## Writing stories

Stories live beside their component, in `apps/web/src/**/*.stories.tsx`. Run Storybook with `pnpm --filter @repo/web dev:stories` and the story tests with `pnpm --filter @repo/web test:stories`.

## Winner Chooses

With the Winner Chooses hand size, someone chooses the hand size before each
deal. The first player chooses for the first round. After that, the first
player to call Yaniv with the lowest hand chooses, and the dealer deals the
size they chose.

![Winner Chooses flow: the first player chooses the first hand size and deals; after each round the winner chooses, and deals straight away if they're also the dealer, otherwise the dealer deals the chosen size](../diagrams/flows/yaniv-winner-chooses.light.svg)
